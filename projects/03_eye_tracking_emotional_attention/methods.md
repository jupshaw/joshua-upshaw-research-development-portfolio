# Methods

## Trial architecture

1. Fixation + auditory cue: total fixation interval 1.40-1.60 s, with notification / control tone / silence conditions
2. Emotional face pair: 3.00 s
3. Probe response: up to 1.20 s
4. Intertrial interval: 0.50-1.00 s

## Calibration and quality

- Standard 9-point calibration
- Mean validation error target <=0.75 degrees
- Maximum validation error target <=1.50 degrees
- Recalibration across experimental blocks
- Trial-level signal-quality criteria

## Endpoints

- First-fixation latency and duration
- Fixation count
- First-saccade metrics
- Blink measures
- Pupil size / baseline-corrected change
- Pupil variability
- Reaction time and accuracy

## Pupil-processing principle

Pupil values were preserved in EyeLink arbitrary units because the study did not use an external physical pupil-size calibration. This avoids falsely presenting pixels/arbitrary units as millimeters.

## Why include secondary projects?

The flagship projects show depth. These projects show **transferability**: the same research habits were applied across different constructs, populations, modalities, and evidence types.

The recurring pattern is:

**define the construct -> select or build the measurement -> execute the study -> evaluate data quality -> analyze -> qualify the conclusion -> communicate what the evidence supports**

# EEG/ERP: Smartphone Notifications and Cognitive Control

**Evidence status:** Peer-reviewed, first-author research  
**Publication:** *PLOS ONE* (2022)  
**DOI:** https://doi.org/10.1371/journal.pone.0277220

## Executive readout

**Problem:** Smartphone notification sounds are ecologically familiar distractors, but behavior alone cannot reveal which processing stage changes.  
**Approach:** Pair notification/control sounds with a local-global visual oddball task while recording EEG and behavior.  
**Result:** Smartphone trials were slightly slower, and N2 amplitude differed between sound conditions, while P3 and several moderation effects did not. The result supported a selective, modest neural effect rather than a broad impairment claim.

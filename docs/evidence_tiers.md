# Evidence Tiers Used in This Repository

| Label | Meaning |
|---|---|
| Peer reviewed | Published in a peer-reviewed journal or scholarly book |
| Preregistered dissertation | Human study with an OSF preregistration and dissertation-level reporting |
| Secondary course project | Completed graduate analysis, not peer reviewed |
| Retrospective feasibility research | Completed analysis of historical data; not a prospective intervention |
| Simulated | Model-based or scenario-based estimate, not an observed real-world effect |
| Proposed | Planned study, endpoint, or pilot stage not yet completed |

These labels are used to prevent a common portfolio failure: presenting all technical work as if it had the same evidentiary status.

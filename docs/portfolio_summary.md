# Portfolio Summary

The full narrative portfolio is available as a PDF in this folder. The GitHub version intentionally reorganizes the same evidence for technical review:

- Project pages emphasize question, method, result, limitation, contribution, and transferable skill.
- Methods pages explain reusable analytical patterns across projects.
- Synthetic demonstrations make the reasoning inspectable without exposing protected or proprietary data.
- The KSA matrix translates research accomplishments into capabilities relevant to R&D and data-science hiring decisions.

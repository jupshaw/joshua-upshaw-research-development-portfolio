# Start Here

This repository is designed for fast review at different levels of depth.

## 2-minute executive path

1. Read the [Executive Summary](docs/executive_summary.md).
2. Scan the [Project Index](PROJECTS.md).
3. Open one flagship project relevant to the role.

The key question is not whether I have used a specific tool. It is whether I can **define the right measurement, build a defensible analysis, identify where the evidence fails, and translate the result into the next technical decision**.

## 10-minute technical path

1. Review [METHODS_MATRIX.md](METHODS_MATRIX.md).
2. Open the relevant project `methods.md` and `results.md` files.
3. Review the public synthetic demonstration in [`examples/`](examples/).
4. For clinical ML, inspect the [Model Card](projects/05_clinical_ai_oncology/MODEL_CARD.md) and [Metric Provenance](projects/05_clinical_ai_oncology/METRIC_PROVENANCE.md).

## 30-minute deep review

Read the full [Research Portfolio PDF](docs/Joshua_Upshaw_Research_Portfolio.pdf), then compare project-specific limitations and next-experiment sections. They show how I handle null results, measurement problems, distribution shift, incomplete observational data, and evidence-to-decision translation.

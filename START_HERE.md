# Start Here

This repository is designed for two audiences.

## 2-minute executive path

1. Read the [Executive Summary](docs/executive_summary.md).
2. Scan the [Project Index](PROJECTS.md) for side-by-side project comparison.
3. Scan the [KSA Evidence Matrix](KSA_EVIDENCE_MATRIX.md).
4. Open one flagship project relevant to the role:
   - [Clinical AI + oncology RWE](projects/05_clinical_ai_oncology/)
   - [EEG/ERP digital distraction](projects/01_eeg_erp_digital_distraction/)
   - [Eye tracking + emotional attention](projects/03_eye_tracking_emotional_attention/)

The key question is not whether I have used a specific tool. It is whether I can **define the right measurement, build a defensible analysis, identify where the evidence fails, and translate the result into the next technical decision**.

## 10-minute technical path

1. Review [METHODS_MATRIX.md](METHODS_MATRIX.md).
2. Open the `methods/` note most relevant to your team.
3. Review one project `methods.md` and `results.md` file.
4. Run a public synthetic example in `examples/` or open the corresponding notebook.
5. For breadth beyond the flagship studies, review [Additional Projects](projects/06_additional_projects/).

## 20-minute leadership and translation path

1. Read [RESEARCH_AND_DEVELOPMENT_APPROACH.md](RESEARCH_AND_DEVELOPMENT_APPROACH.md).
2. Review [Scientific Leadership, Service, and Communication](docs/scientific_leadership_and_service.md).
3. Scan [Research Governance](methods/research_governance.md).

## 30-minute deep review

Read the full [Research Portfolio PDF](docs/Joshua_Upshaw_Research_Portfolio.pdf), then compare the project-specific limitations and next-experiment sections. They show how I handle nulls, measurement problems, distribution shift, and incomplete observational data.
